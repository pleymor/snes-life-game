# Self-Playing Tutorial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `HOW TO PLAY` menu entry that plays nine commented mini-lessons on prepared boards, driven by the real game engine, with English captions under the HUD; the demo advances on its own, A skips to the next lesson, START returns to the menu.

**Architecture:** A new pure module `src/core/tutorial.c` holds a flat ROM script of `{op, a, b}` byte triples and a player (`TutPlayer`) that applies it to an ordinary `Match` through `match.c` (two small additions there: `match_tick`, `match_begin_turn`). Host tests check each lesson's outcome. On the console, `screen_tutorial()` runs the usual prepare → `WaitForVBlank()` → `render_vblank()` loop, feeds the player the real elapsed frames, and a new render function transfers three caption rows of BG2.

**Tech Stack:** C89 (host: clang `-std=c89 -pedantic -Werror -fsanitize=address,undefined`; console: PVSnesLib 4.6.0 / 816-tcc), Python 3 (tile generator), GNU Make.

**Spec:** `docs/superpowers/specs/2026-09-27-tutorial-design.md`

## Global Constraints

- `src/core/` includes only `<string.h>` and core headers; no PVSnesLib, no `printf`, no `ctype.h`.
- Strict C89: no `//` in `src/core/` and `tests/`, no declarations after statements, no `inline`, no compound literals, no designated initialisers, no `long long`, no floats.
- On the console `int` and `long` are 16 bits; RAM is not zeroed at boot (every static set explicitly in its init path); `static const` tables one-dimensional and file-scope so they stay in ROM; no automatic variable over 64 bytes; no table of pointers to strings (captions come from a `switch`).
- Tile indices 0 to 83 keep their meaning and pixels; the comma is tile 84 (`TILE_COMMA`).
- On-screen text is English, uppercase, at most 32 characters per line, 3 lines per caption.
- Rendering is two-phase: prepare functions fill RAM buffers and set pending flags; only `render_vblank()`, right after `WaitForVBlank()`, writes VRAM.
- C statics must end below 7E:8000 (the build's RAM guard checks it).
- Commit format: `<gitmoji> [scope] <description>`, one gitmoji, scope among `[core]`, `[snes]`, `[tools]`, `[build]`, `[docs]`. Never name an assistant tool or AI.
- Captures only through the capture skill: `caffeinate -u bash ~/.claude/skills/capturing-snes-screens-headless/scripts/cap.sh <rom> <frames> <out.png> [limit_s]`; never launch RetroArch directly.

## Review Focus

- A pressed on the last lesson (or after the end) must end the tutorial cleanly, not index past the script. — Task 3 test `test_passer_au_dela_de_la_derniere_lecon_termine`.
- A very large elapsed-frame count (the first frame after a slow rebuild, or 1000 at once) must give exactly the same result as frame-by-frame play. — Task 3 test `test_le_decoupage_des_images_ne_change_rien`.
- Starting the tutorial from garbage memory (0x55) must play exactly like a clean start. — Task 3 test `test_le_tutoriel_ne_depend_pas_de_la_memoire`.
- Leaving the tutorial (START, or its end) must leave no caption, cursor or tutorial board behind in the menu or the next game. — Task 6 captures after the end.
- A START already held when entering the tutorial from the menu must not immediately leave it. — covered by the existing edge detection (`input_edges`); Task 6 capture shows lesson 1 after entering.

/* Exécute une opération qui n'est pas une attente. */
static void exec_op(TutPlayer *p, Match *m, int i)
{
    switch (OP(i)) {
    case TUT_LESSON:
        p->lesson = A(i);
        p->cursor_on = FALSE;
        p->show_range = FALSE;
        break;
    case TUT_START:
        match_start(m);
        break;
    case TUT_CLEAR:
        match_start(m);
        board_clear(&m->board);
        match_begin_turn(m, CELL_P1);
        break;
    case TUT_CELL_P1:
        board_set(&m->board, A(i), B(i), CELL_P1);
        break;
    case TUT_CELL_P2:
        board_set(&m->board, A(i), B(i), CELL_P2);
        break;
    case TUT_READY:
        match_begin_turn(m, CELL_P1);
        break;
    case TUT_ROUND:
        m->round = A(i);
        break;
    case TUT_TEXT:
        p->caption = A(i);
        break;
    case TUT_RANGE:
        p->show_range = (bool_t)(A(i) != 0);
        break;
    case TUT_CURSOR:
        p->cursor_x = A(i);
        p->cursor_y = B(i);
        p->cursor_on = TRUE;
        break;
    case TUT_NOCURSOR:
        p->cursor_on = FALSE;
        break;
    case TUT_PLACE:
        p->cursor_x = A(i);
        p->cursor_y = B(i);
        match_place(m, A(i), B(i));
        break;
    case TUT_ENDTURN:
        match_end_turn(m);
        break;
    case TUT_TICK:
        match_tick(m);
        break;
    default:
        break;
    }
}

bool_t tut_update(TutPlayer *p, Match *m, int frames)
{
    bool_t changed = FALSE;

    if (p->done) return FALSE;
    for (;;) {
        if (p->wait > 0) {
            if (frames < p->wait) {
                p->wait -= frames;
                return changed;
            }
            frames -= p->wait;
            p->wait = 0;
        }
        if (OP(p->pc) == TUT_END) {
            p->done = TRUE;
            return TRUE;
        }
        if (OP(p->pc) == TUT_WAIT) {
            p->wait = A(p->pc);
        } else {
            exec_op(p, m, p->pc);
            changed = TRUE;
        }
        p->pc++;
    }
}

void tut_start(TutPlayer *p, Match *m)
{
    p->pc = 0;
    p->wait = 0;
    p->lesson = 0;
    p->caption = -1;
    p->cursor_x = 0;
    p->cursor_y = 0;
    p->cursor_on = FALSE;
    p->show_range = FALSE;
    p->done = FALSE;
    match_start(m);
    tut_update(p, m, 0);
}

void tut_skip(TutPlayer *p, Match *m)
{
    int i = p->pc;
    if (p->done) return;
    while (OP(i) != TUT_LESSON && OP(i) != TUT_END) i++;
    if (OP(i) == TUT_END) {
        p->done = TRUE;
        return;
    }
    p->pc = i;
    p->wait = 0;
    tut_update(p, m, 0);
}

bool_t tut_lesson_done(const TutPlayer *p)
{
    return (bool_t)(!p->done && p->wait > 0 &&
                    (OP(p->pc) == TUT_LESSON || OP(p->pc) == TUT_END));
}

void screen_tutorial(Match *m)
{
    /* Hors pile et posés à chaque appel : la RAM n'est pas remise à zéro. */
    static TutPlayer p;
    static u8 caption[3][HUD_W];
    static u8 banner[HUD_W];
    u16 last, now;
    bool_t changed = TRUE;

    tut_start(&p, m);
    last = (u16)snes_vblank_count;

    for (;;) {
        unsigned short hit = input_edges((unsigned short *)0);

        if (hit & KEY_START) break;
        if (hit & KEY_A) {
            tut_skip(&p, m);
            changed = TRUE;
        }
        now = (u16)snes_vblank_count;
        if (tut_update(&p, m, (int)(u16)(now - last))) changed = TRUE;
        last = now;
        if (p.done) break;

        if (changed) {
            render_board_now(m, p.show_range);
            if (match_winner(m) != WINNER_NONE) {
                view_result_banner(m, banner);
                render_hud_from_row(banner);
            } else {
                render_hud_dirty();
            }
            view_caption(p.caption, caption);
            render_caption(caption);
            changed = FALSE;
        }
        if (match_winner(m) == WINNER_NONE) {
            render_hud_now(m, (bool_t)((((unsigned int)(u16)snes_vblank_count / 15) & 1U) == 0U));
        }
        render_cursor(p.cursor_x, p.cursor_y, p.cursor_on);

        WaitForVBlank();
        render_vblank();
    }

    view_caption(-1, caption);
    render_caption(caption);
    render_cursor(0, 0, FALSE);
    WaitForVBlank();
    render_vblank();
}
